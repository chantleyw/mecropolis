# Decisions

| Decision                                                                                                      | Reason                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Derive season stage from GDD instead of manual entry                                                          | No usable crop-calendar API covers South Africa (FAO excludes it; others paid or unreachable).                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Never populate `season.yieldAmount` from statistics                                                           | Regional numbers shown as a field's yield would be synthetic data.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Benchmarks in their own `benchmark` documents, no ratio to field yield                                        | Keeps regional context visibly separate; dryland Western Cape wheat versus a maize-weighted national mean is not like for like.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Crop model has no category fallback                                                                           | Wheat base about 0 C versus maize about 10 C; an unknown crop must fail, not borrow parameters.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Next 16, not 15                                                                                               | Next 15 bundles a vulnerable PostCSS; `next-sanity` 13 needs `next ^16`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| HarvestStat committed as a 208 KB extract, not fetched at runtime                                             | Static MIT data; the 1 MB source CSV is rebuilt by `scripts/extract-harveststat.mjs`. Province-level rows only, month columns dropped (upstream says `planting_month` is not phenology).                                                                                                                                                                                                                                                                                                                                                                               |
| HarvestStat `admin_2` double-counting: not a risk                                                             | Verified 2026-09-21: all 8110 ZA rows have `admin_2 = none`, one production system, no duplicate province/product/year. The CSV has no `qc_flag` column; the extractor drops non-numeric or non-positive values (none were dropped).                                                                                                                                                                                                                                                                                                                                   |
| PSD key passed as an argument                                                                                 | Keeps `psd.ts` free of env access and testable.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| PSD queried per year, unit id mapped explicitly                                                               | The endpoint is per year; an unmapped unit id throws instead of guessing a factor.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `seasonWindow` end bounded at 2x `growthCycleDays`                                                            | Author's choice, not in the plan.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Crop `gddModelKey` field                                                                                      | Seeded crop names such as "Wheat (SST 88)" never matched `cropModelFor`, so GDD and the reconciler were dead; the key is now explicit on the crop.                                                                                                                                                                                                                                                                                                                                                                                                                     |
| Field `coordinates` optional, falls back to the farm point                                                    | The seed sets no field coordinates, so fields in one farm share weather; farm points are approximate town centres.                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `AuthBoundary` renders its own login/callback UI; no `/auth/callback` route or `LoginCallback`/`useLoginUrls` | `@sanity/sdk-react@3.3.0` exports neither; `AuthBoundary` takes `LoginComponent`/`CallbackComponent`/`LoginErrorComponent` overrides instead, and the real hook is `useLoginUrl` (singular). The App SDK plan's Milestone 1 text assumed the old shape; confirmed against installed `.d.ts`, not memory.                                                                                                                                                                                                                                                               |
| SPA deploy target moved from Vercel to Cloudflare Pages (2026-09-22), `vercel.json`/`.vercel/` deleted        | Vercel refused the deploy over the commit-author email (`36380517+chantleyw@users.noreply.github.com`); the rebuild plan's Context already listed the stuck Vercel Next build as a blocker the rebuild was meant to clear, so the host was leaving anyway. See `~/.claude/plans/vercel-is-a-headache-velvety-grove.md`.                                                                                                                                                                                                                                                |
| Cron dropped, not moved to Cloudflare                                                                         | `/api/advance`'s `CRON_SECRET` bearer-auth path stays until Milestone 8 removes the Next app, but nothing schedules a call to it now.                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Milestone 8's `vercel.json` → `{"framework": "vite"}` step is obsolete                                        | There is no Vercel config left to change; Milestone 8 deploys the Vite build to Cloudflare Pages instead.                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Observation writes capped globally at 60/hour by counting in Sanity (2026-09-23)                              | In-memory limiters are per isolate; Pages rejects `[[ratelimits]]` and WAF rules do not cover `*.pages.dev`. Sanity is already the shared store, so no new infra. Chosen by user over KV counters, a standalone Worker, or accepting the gap. IPv6 clients are keyed on their /64.                                                                                                                                                                                                                                                                                     |
| Regional degree-day grid stored in Sanity and accumulated incrementally (2026-09-23)                          | The landing map (M3b redesign) needs 187 Open-Meteo points since 1 May; fetched whole that is about 2,000 calls per refresh against 600/min and 10,000/day free limits, and per-isolate caches would refetch it. Chosen by user over a 0.5° grid or per-isolate caching.                                                                                                                                                                                                                                                                                               |
| M3b redesign: regional weather-map world, light chrome (2026-09-23)                                           | User rejected the Living Almanac look and three rolled directions; pinned a Windy/Ventusky-style regional field (sketch A) with light panels. Direction contract in `.impeccable/surfaces/src-pages-landing-tsx.md`.                                                                                                                                                                                                                                                                                                                                                   |
| Landing map: MapLibre GL JS 6 with OpenFreeMap `positron` vector tiles (2026-09-23)                           | User asked for a real map. OpenFreeMap needs no key or account; attribution (OpenFreeMap, OpenMapTiles, OpenStreetMap) comes from the style and shows in MapLibre's control. The grid is a GeoJSON fill layer under the base map labels, one square per Open-Meteo point, coloured by `ramp.ts`; farms are MapLibre markers rendered by React portals. `RegionMap` is lazy-loaded (about 281 kB gzip plus a 510 kB worker built with Vite `?worker&url`). Cooperative gestures so the page still scrolls. Only the light `positron` style is used, also in dark theme. |
| Logo: seedling over a row of four ramp cells (2026-09-23)                                                     | The four-square mark read as the Windows logo; the user asked to restore the seedling and tie it to the map's grid cells.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Landing conditions stay on the Swartland demo site, not the farm picked on the map (2026-09-23)               | Following the selection would need `/api/conditions` opened to signed-out visitors. User chose to keep the section fixed on `DEMO_SITE`.                                                                                                                                                                                                                                                                                                                                                                                                                               |
| CSP in `public/_headers` without `style-src 'unsafe-inline'` (2026-09-24)                                     | MapLibre and React set styles through the CSSOM, which CSP does not block; every route loaded with zero violations. Theme script allowed by sha256, kept in sync by `src/csp.test.ts`. `api.` and `climate-api.open-meteo.com` are in `connect-src` as the plan listed, though today only `archive-api.` is called from the browser.                                                                                                                                                                                                                                   |
| MIT license, GitHub Actions CI without `format:check` (2026-09-24)                                            | Plan default. `format:check` fails on 17 pre-existing files, so CI runs typecheck, lint, test, build and audit.                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Season summary uses Sanity Agent Actions, not Gemini (2026-09-24)                                             | Agent Actions run on Sanity's hosted model with Sanity AI credits (Free: 1000/month) and cannot use an outside model; a Gemini call would not be a Sanity feature and would add a key.                                                                                                                                                                                                                                                                                                                                                                                 |
| Sanity Functions call `/api/advance` with the `CRON_SECRET` bearer (2026-09-24)                               | Keeps one reconciler (Open-Meteo fetch, guards, transaction) in Pages Functions; the Sanity document and scheduled functions only trigger it.                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Dataset Embeddings, not the Embeddings Index API (2026-09-24)                                                 | The Index API is deprecated and Growth-only; Dataset Embeddings work on all plans via `text::semanticSimilarity`, 500 queries/month on Free, so search goes through a capped Function.                                                                                                                                                                                                                                                                                                                                                                                 |
| Season notes are separate dated entries in the season document (2026-09-24)                                   | User asked for per-note add/edit and a restore that affects only the chosen note. Kept as an array on the season (not separate documents) so one History API timeline covers every note; capped at 100 per season. Old single-field notes migrated by `scripts/migrate-notes.ts`.                                                                                                                                                                                                                                                                                      |
| Notes are owned by whoever wrote them (2026-09-24)                                                            | User: ownership is part of the architecture; the shared demo login is only this deployment. Sessions carry a writer id (user id, or a random visitor id for the demo login); only the owner may edit, delete or restore a note, enforced in the Functions. Unowned (migrated) notes are read-only.                                                                                                                                                                                                                                                                     |

## Open

- Crop model parameters are hand-authored and uncited.
- HarvestStat has "Sweet Lupin" for Western Cape (2000 to 2007 only, 24 rows), contradicting the earlier note that lupins are in neither source. Whether narrow-leafed lupin should map to it is undecided; the crop's `harvestStatProduct` field decides, so no mapping is hard-coded.
- Open-Meteo archive tail lag (coverage guard is 90%; may need `pastDays`).
